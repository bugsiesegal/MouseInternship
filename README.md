# Brain Wave Autoencoder: Attempt #1 🧠

## The Beginning of a 5-Year Journey

This repository marks the first step in what would become a half-decade quest to decode mouse brain activity. Spoiler alert: it didn't work. But every journey starts somewhere, and this one started with a CNN where it probably shouldn't have.

## Project Overview
An ambitious (read: overconfident) attempt to:
- Read mouse brain waves
- Process them through an autoencoder
- Understand what mice are thinking
- Make a GUI to visualize it all
- Question every life decision that led to this point

## Technical Details
- **Architecture**: CNN autoencoder (because why use appropriate architectures when you can use inappropriate ones?)
- **Interface**: First attempt at Kivy GUI
- **Success Rate**: Approximately 0%
- **Mental State Post-Project**: Slightly damaged but resilient

## Components
- **GUI**: A Kivy interface that theoretically should display brain wave data
- **Autoencoder**: A CNN that steadfastly refused to decode brain activity
- **Dreams**: Crushed, but eventually rebuilt in subsequent attempts

## What I Learned
1. CNNs are not the answer to everything
2. Brain waves are complicated
3. Mouse minds are not easily read
4. GUI development is its own special kind of challenge
5. Sometimes failure is the best teacher
